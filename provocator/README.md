# 🔥 ПРОВОКАТОР

**Симулятор злого модератора чата.** Браузерная single-page игра в реальном времени.

Снаружи — дружелюбный модератор со значком 🛡️. Внутри — поджигатель срачей. Твоя задача — **разогнать Градус (Toxicity) чата до неба**, не спалиться перед админом и не забанить всех живых душ.

## Запуск

Это статика на чистом HTML/CSS/ES-модулях, без сборки.

```bash
cd provocator
python3 -m http.server 8000
# открой http://localhost:8000/
```

## Игровые механики

### 4 шкалы
- **🔥 Градус (Toxicity)** — главная цель. Растёт от срачей, медленно остывает.
- **👁️ Sus** — палевность. Растёт от очевидных провокаций и банов невиновных. 100 = тебя сняли.
- **👥 Актив (Online)** — народ в чате. Если забанишь всех — срачиться будет некому.
- **💢 Срачемер (Combo)** — множитель Toxicity ×1.0 .. ×5.0. Накапливается при цепной реакции.

### Действия на сообщении
| Действие | Что делает |
|---|---|
| 🗑️ Удалить | Чистит токсик-фразу (немного снижает Sus). Удалить жалобу = +Sus. |
| 🚫 Бан | Удаляет юзера. Бан адеквата = огромный Sus. Бан спамера = -Sus. |
| ⚠️ Варн | Системка с предупреждением, юзер бесится и пишет злее. |
| 📌 Закреп | Пинит провокацию — мощный буст Градуса. Чат разносит. |
| 👁️ Тенебан | Юзер пишет в пустоту, бесится бесконечно. Игрок видит, остальные — нет. |
| 👍 Лайк | Подбадривает токсичного юзера на новые подвиги. |

### Скиллы модератора (с КД)
- 💬 **Вброс** (60с) — выбираешь провокационный тейк, чат раскалывается на лагеря.
- 🤖 **Газлайт** (30с) — системка «Пользователь N был предупреждён за глупость».
- 🔥 **Раздуть** (45с) — буст Срачемера и волна реакций на свежий конфликт.
- 🤐 **Глушилка** (90с) — 6 секунд тишины, снимает 6 Sus.

### Архетипы
- **терпила** — пишет жалобы. Игнор → идёт к админу (+Sus).
- **тролль-интеллектуал** — топливо срача, не банить!
- **капсхейтер** — кричит капсом, идеальная мишень для показных банов.
- **олдфаг** — ноет про «раньше было лучше». Бан → уводит фолловеров.
- **адекват** — гасит срач. Бан = огромный Sus.
- **спам** — рекламные боты, бан безопасен.
- **новичок** — задаёт глупые вопросы, бан → +Sus.
- **знаменитость** — иногда заходит, ловит фанатов.

### Случайные события
- 👁️ **Админ зашёл** — Sus умножается на 1.7 пока он смотрит.
- 🚨 **Рейд** — толпа капс-хейтеров из соседнего чата, 15 секунд хаоса.
- 🌟 **Звезда в чате** — приходит блогер, фанаты сходят с ума.
- 👶 **Волна новичков** — приток актива, но и шум вопросов.

## Управление
- ESC — пауза.
- M — mute.
- Hover на сообщение — действия модератора.

## Технологии

Vanilla JS (ES modules), CSS (без препроцессоров), HTML, WebAudio для синтезированных звуков. Без сборки и без зависимостей.
